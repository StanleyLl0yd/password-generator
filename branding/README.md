# App icon

`app-icon.webp` is the approved canonical app icon artwork for Password Generator.

Do not redraw, recolor, restyle, crop, replace, or otherwise alter this artwork unless the project owner explicitly requests a new icon. Resizing and format conversion are allowed only when required for Android launcher resources or store assets, while preserving the artwork itself.

`store-icon-512.png` is the store-ready 512 px export generated from the same approved artwork. Android launcher resources under `app/src/main/res/mipmap-*` and the adaptive foreground under `app/src/main/res/drawable-nodpi` must always be derived from `app-icon.webp`.
