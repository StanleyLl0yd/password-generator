Приватный офлайн-генератор паролей для Android. Пароли создаются локально с использованием `SecureRandom`; у приложения нет разрешения на доступ в интернет, и сгенерированные данные никуда не отправляются.

**Версия исходного кода:** 1.5.0 (`versionCode 11`) · **Android:** 7.0+ (API 24) · **Target SDK:** 36

[GitHub Releases](https://github.com/StanleyLl0yd/password-generator/releases)

## Возможности

- Длина пароля от **4 до 64** символов.
- Четыре независимо включаемых набора символов:
  - строчные буквы `a-z`;
  - заглавные буквы `A-Z`;
  - цифры `0-9`;
  - спецсимволы `!@#$%^&*()-_=+[]{};:,.<>?/|`.
- В сгенерированный пароль входит как минимум один символ из каждого включённого набора.
- Можно исключить визуально похожие символы: `i I l 1 o O 0 B 8 G 6 S 5 Z 2`.
- Можно полностью запретить повторение символов; если выбранного набора недостаточно для заданной длины, приложение сообщает об ошибке и не ослабляет это правило.
- Управление длиной: ползунок, кнопки `-` / `+` и быстрые значения **16**, **24** и **32** символа.
- Сгенерированный пароль доступен только для чтения, по умолчанию скрыт; его можно показать или скопировать.
- Индикатор надёжности оценивает сгенерированный пароль; оценка снижается за малую длину, последовательности, большое число повторов, повторяющиеся блоки и распространённые слабые шаблоны.
- Настройки генератора сохраняются между запусками.
- Интерфейс Material 3 следует системной светлой/тёмной теме и использует Dynamic Color на Android 12+.
- Интерфейс на английском и русском языках.
- Раздел **«О приложении»** показывает установленную версию, краткое описание, автора, лицензию и ссылку на репозиторий GitHub.

## Приватность и буфер обмена

- У приложения **нет разрешения `INTERNET`**.
- В проекте нет SDK аналитики, рекламы или трекинга.
- Сгенерированные пароли находятся только в памяти и **не сохраняются в постоянное хранилище**.
- В DataStore сохраняются только настройки генератора.
- Настройки генератора исключены из облачного резервного копирования Android и переноса данных между устройствами.
- Скопированный пароль помечается как конфиденциальный и планируется к удалению из буфера через **60 секунд**.
- Автоочистка удаляет только тот пароль, который всё ещё находится в буфере; более новое содержимое буфера не затрагивается.

О проблемах безопасности сообщайте согласно [SECURITY.md](SECURITY.md).

## Сборка из исходного кода

Требуются JDK 17 и Android SDK 36.

```bash
git clone https://github.com/StanleyLl0yd/password-generator.git
cd password-generator
./gradlew assembleDebug
```

Основные проверки, используемые CI:

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug assembleRelease bundleRelease
```

Основной стек: Kotlin 2.2.0, Jetpack Compose, Material 3, Hilt, Coroutines/Flow и DataStore Preferences.
