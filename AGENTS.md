# Project instructions

## Branding

- `branding/app-icon.webp` is the canonical approved Password Generator app icon.
- Do not redraw, recolor, restyle, crop, replace, or otherwise alter the icon artwork unless the project owner explicitly requests it.
- Every Android release must use launcher assets derived from this exact artwork.
- Store listing icons must be derived from the same artwork.
- Resizing and format conversion are allowed only when required by Android or store specifications; the composition, colors, symbols, text, lighting, and other visual elements must remain unchanged.
- Before every release, verify that `@mipmap/ic_launcher` and `@mipmap/ic_launcher_round` resolve to assets derived from `branding/app-icon.webp`.
