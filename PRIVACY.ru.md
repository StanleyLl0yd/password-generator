# Политика конфиденциальности

Последнее обновление: 18 сентября 2026 года

Password Generator — приватный офлайн-генератор паролей с нативными приложениями для Android, Windows и macOS.

## Сбор данных

Password Generator не собирает, не передаёт, не продаёт и иным образом не раскрывает персональные данные или сведения об использовании приложения.

Приложение не использует аналитику, рекламные SDK, технологии отслеживания, телеметрию, сервисы отправки отчётов о сбоях, облачную синхронизацию, удалённые учётные записи или серверную часть.

## Доступ к сети

Password Generator не требует сети для генерации паролей или какой-либо другой функции приложения.

Android-приложение не запрашивает разрешение `INTERNET`. Windows- и macOS-версии не содержат сетевой функциональности продукта.

Ссылки из раздела «О приложении» передаются операционной системе и открываются во внешнем приложении, например браузере. Сетевой обмен, возникающий после открытия такой ссылки, относится к внешнему приложению или сайту, а не к Password Generator.

## Пароли

Пароли создаются локально с использованием криптографического генератора случайных чисел операционной системы:

- Android: `SecureRandom`;
- Windows: `BCryptGenRandom`;
- macOS: `SecRandomCopyBytes`.

Сгенерированные пароли находятся только в оперативной памяти процесса и не сохраняются Password Generator в постоянное хранилище.

Когда пользователь явно раскрывает пароль, приложение включает максимально практичную нативную защиту от захвата экрана, доступную на соответствующей платформе. Это best-effort защита средствами ОС; она не может предотвратить фотографирование экрана или захват привилегированным/скомпрометированным ПО.

## Буфер обмена

При копировании пароль помещается в системный буфер обмена.

Там, где платформа предоставляет соответствующий механизм, Password Generator обрабатывает значение как конфиденциальное и планирует очистку через 60 секунд. Очистка выполняется условно: приложение удаляет только своё значение, если оно всё ещё остаётся текущим, и не стирает содержимое, которое позднее скопировал пользователь или другое приложение.

Работа буфера обмена также зависит от политик операционной системы и другого ПО, имеющего к нему доступ.

## Локальные настройки

Password Generator сохраняет только несекретные настройки генератора: длину, выбранные наборы символов и параметры генерации.

Хранилище по платформам:
- Android: DataStore;
- Windows: раздел текущего пользователя в Registry;
- macOS: UserDefaults.

Сгенерированные пароли в настройках не сохраняются.

На Android резервное копирование данных приложения отключено, а правила backup/переноса между устройствами явно исключают настройки генератора.

## Разрешения и возможности платформ

Android запрашивает только `android.permission.VIBRATE` для тактильной обратной связи и не запрашивает разрешение `INTERNET`.

Windows-приложение работает с правами текущего пользователя без повышения привилегий и использует нативные API интерфейса, криптографического RNG, буфера обмена и пользовательского Registry.

macOS-приложение использует нативные AppKit/Foundation/Security и упаковывается с включённым App Sandbox. Для функций продукта сетевой entitlement не требуется.

## Дети

Password Generator не собирает данные ни у кого, включая детей, поскольку приложение вообще не собирает персональные данные или сведения об использовании.

## Сторонние сервисы

Приложение не интегрирует сторонние сервисы аналитики, рекламы, отслеживания, авторизации, облака или телеметрии.

Раздел «О приложении» содержит ссылки на официальный сайт проекта, лицензию и эту Политику конфиденциальности. Ссылки открываются операционной системой во внешнем приложении. Обработка данных выбранным браузером, внешним приложением или сайтом регулируется их собственными условиями конфиденциальности.

## Изменения политики

Если практика обработки данных Password Generator изменится, эта Политика конфиденциальности будет обновлена до выпуска или одновременно с выпуском соответствующей версии.
